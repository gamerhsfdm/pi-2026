MUDANÇAS REALIZADAS - PAINEL ADMINISTRATIVO (EDITOR DE SEÇÕES)
================================================================

RESUMO
------
1. Novas cores editáveis por elemento (marcador, destaque, listas, botões, cards, cronograma, estatísticas).
2. Controles do painel organizados por seção (cada seção mostra só o que funciona nela).
3. Preview fiel ao site principal em todas as seções (usa o próprio index.php, com o mesmo CSS e JS).

ARQUIVOS (5)
------------
[NOVO]       admin/section_preview.php
[SUBSTITUIR] admin/editor.php
[SUBSTITUIR] includes/section_style.php
[SUBSTITUIR] assets/css/section-styles.css
[SUBSTITUIR] index.php


1) admin/section_preview.php  (ARQUIVO NOVO - criar na pasta admin)
-------------------------------------------------------------------
- Recebe por POST os campos do formulário do editor (ainda não salvos).
- Exige login e token CSRF. Não grava nada no banco e não conta visita.
- Monta os mesmos dados que o salvamento do editor montaria (textos, estilo validado por
  sanitizeSectionStyle, vídeo de fundo, itens internos).
- Define SX_SECTION_PREVIEW e inclui o index.php, que gera o HTML real do site.
- Injeta no HTML: <base> das URLs, CSS que esconde as outras seções, script que mostra o estado
  final das animações, bloqueia navegação dos links e informa a altura da seção ao painel.


2) admin/editor.php
-------------------------------------------------------------------
Painel "Aparência e layout":
- Organização por tipo de seção (hero, sobre, mapa, cultura, empreendedorismo, conhecimento,
  cronograma, rodapé e seções personalizadas). Só aparecem os controles que valem para a seção.
- Aba Cores agrupada: Textos | Marcador e destaques | Botões do banner | Cards | específicas
  (Objetivos, Estatísticas, Linha do tempo, Mapa).
- Novos campos de cor: badge_color, badge_bg, highlight_color, list_marker_color,
  btn_primary_bg, btn_primary_text, btn_secondary_bg, btn_secondary_text, btn_secondary_border,
  card_title_color, card_desc_color, card_subtitle_color, card_icon_bg, timeline_color,
  stat_number_color.
- Cores de card (fundo, texto, borda) saíram da aba Cards e foram para a aba Cores.
- Aba Imagem só aparece onde a imagem é usada (seção personalizada, mapa, empreendedorismo).
- Aba Cards só aparece onde existem cards; no banner a aba vira "Botões".
- Cores padrão mostradas nos seletores passaram a espelhar o CSS real de cada seção.
- Controles ocultos são reenviados em campos escondidos, para não perder valores já salvos.
- Rótulo "Selo" passou a "Marcador".
- Ícone da aba Fundo trocado (era igual ao da aba Imagem).

Preview:
- Preview antigo (mockup simulado) removido.
- Novo preview em iframe com o site real: botões Desktop / Tablet / Celular, Ampliar (Esc fecha),
  atualização automática ao editar qualquer campo, status de atualização.
- iframe com sandbox (isolado do painel).

JavaScript:
- Removido todo o código que simulava o preview.
- Corrigido erro na lista de itens da seção Cultura (variável BASE inexistente no trecho antigo).
- Aviso de contraste agora também confere subtítulo e descrição.


3) includes/section_style.php
-------------------------------------------------------------------
- SX_COLOR_FIELDS recebeu os 15 novos campos de cor.
- Nova constante SX_EXTRA_COLORS (campo => classe CSS, variável CSS).
- sectionStyleClasses() e sectionStyleInline() passaram a aplicar as novas cores.
- Estilos antigos já salvos continuam funcionando (campos novos entram vazios).


4) assets/css/section-styles.css  (regras adicionadas no FINAL do arquivo)
-------------------------------------------------------------------
- Regras do marcador (cor e fundo), palavra destacada, marcações de lista, botões do banner.
- Cards: título, descrição, frase de apoio e fundo do ícone.
- Fundo, texto e borda de card agora também valem para os "destaques" da seção de
  empreendedorismo e para os itens de seções personalizadas.
- Números das estatísticas e linha/pontos do cronograma.
- Correção de precedência: a cor do subtítulo não é mais sobrescrita pela cor da descrição
  nem pela cor do texto geral.
- Nenhuma regra antiga foi alterada.


5) index.php
-------------------------------------------------------------------
- Adicionado um único bloco (antes da linha "Só páginas geradas com dados reais do banco...").
- O bloco só age quando a constante SX_SECTION_PREVIEW existe (somente dentro do preview do painel).
- Para os visitantes do site, não muda nada.


COMO INSTALAR
-------------
1. Copie admin/section_preview.php para a pasta admin do projeto (arquivo novo).
2. Substitua os outros 4 arquivos pelos novos, mantendo as mesmas pastas.
3. Atualize o painel com Ctrl+F5.


OBSERVAÇÕES
-----------
- Não foi possível rodar PHP/MySQL no ambiente de desenvolvimento; teste o editor em uma seção
  real antes de publicar.
- Bug existente no site (não alterado): no banner, se o subtítulo estiver preenchido, a descrição
  fica invisível, porque o assets/js/index.js só revela o primeiro parágrafo do banner.
