MODIFICACOES — personalização de cores no editor

Objetivo
Separar as cores de título, subtítulo, descrição e texto geral por seção.

1. includes/section_style.php

Na constante SX_COLOR_FIELDS, adicionar:
    'subtitle_color'
    'description_color'

O resultado deve conter os dois campos entre title_color e body_color:
    const SX_COLOR_FIELDS = ['bg_color', 'bg_color2', 'title_color', 'subtitle_color', 'description_color', 'body_color', 'accent_color', 'card_bg', 'card_text', 'card_border_color'];

Em sectionStyleClasses(), depois da classe sx-tc, adicionar:
    if (isset($s['subtitle_color']) && $s['subtitle_color'] !== '') $c[] = 'sx-stc';
    if (isset($s['description_color']) && $s['description_color'] !== '') $c[] = 'sx-dc';

Em sectionStyleInline(), depois da variável --sx-title-color, adicionar:
    if (!empty($s['subtitle_color'])) $v[] = '--sx-subtitle-color:' . $s['subtitle_color'];
    if (!empty($s['description_color'])) $v[] = '--sx-description-color:' . $s['description_color'];

2. admin/editor.php

Na aba "Cores", substituir a única opção "Cor do texto" por estas opções:
    $sxColor('subtitle_color', 'Cor do subtítulo', 'Usada somente quando a seção tiver um subtítulo.');
    $sxColor('description_color', 'Cor da descrição', 'Texto descritivo abaixo do título.');
    $sxColor('body_color', 'Cor do texto geral', 'Parágrafos e listas fora dos cards.');

No JavaScript do preview, a cor de liveSub deve usar:
    val('subtitle_color') || val('description_color') || val('body_color')

3. assets/css/section-styles.css

Depois das regras .sx-tc e .sx-bc, adicionar:
    .sx-stc .sx-subtitle { color: var(--sx-subtitle-color) !important; }
    .sx-dc .sx-description,
    .sx-dc :is(.titulo-section, .section-header) > p,
    .sx-dc .hero-content > p { color: var(--sx-description-color) !important; }

4. index.php

Em cada seção padrão (hero, sobre, mapa, cultura, empreendedorismo,
conhecimento e cronograma), adicionar classes semânticas:

    <?php if (!empty($secao['subtitle'])): ?>
      <p class="sx-subtitle"><?= e($secao['subtitle']) ?></p>
    <?php endif; ?>
    <p class="sx-description"><?= e($secao['description'] ?? '') ?></p>

Trocar $secao pelo array correto: $hero, $sobre, $mapa, $cultura, $emp,
$conhecimento ou $cronograma.

Nas seções personalizadas, aplicar:
    class="sx-subtitle" no parágrafo do subtítulo
    class="sx-description" no bloco da descrição

Resultado
Cada seção passa a salvar e aplicar suas próprias cores para título,
subtítulo, descrição e texto geral. O subtítulo também passa a ser exibido
no site quando estiver preenchido.

5. Paleta do site principal no painel

Em admin/editor.php, substituir a constante PALETTE por:
    const PALETTE = ['#ff2d2d', '#e02424', '#111827', '#64748b', '#4b5563', '#ffffff', '#e5e7eb', '#fafafa', '#f3f4f6', '#f1f5f9', '#e2e8f0', '#94a3b8', '#cbd5e1'];

Essas são as cores já definidas no arquivo assets/css/style.css. Elas
aparecem como atalhos circulares em todos os campos de “Aparência e layout > Cores”.

6. Exibição correta do padrão no painel

No helper $sxColor de admin/editor.php, usar cores padrão do site somente para
exibição do seletor quando o valor salvo estiver vazio. Mapa recomendado:
    título: #111827; subtítulo: #4b5563; descrição/texto: #64748b;
    destaque: #ff2d2d; fundo: #fafafa; card: #ffffff; borda: #e5e7eb.

No preview JavaScript, usar esses mesmos valores como fallback e fundo #ffffff.
Assim, uma seção sem personalização aparece no painel com o visual claro do
site principal, sem gravar cores novas automaticamente.

7. Quadro Objetivos e Competências (seção Sobre)

Adicionar objectives_bg e objectives_text a SX_COLOR_FIELDS em
includes/section_style.php, gerando as classes sx-ob e sx-ot e as variáveis
--sx-objectives-bg e --sx-objectives-text.

No CSS, aplicar as variáveis em .objetivos-box. No painel, adicionar os campos:
    Fundo de Objetivos e Competências
    Texto de Objetivos e Competências

Eles editam exclusivamente o quadro vermelho da seção “Sobre o Projeto”.

8. Elementos exclusivos do Mapa Interativo

Adicionar campos de cor próprios para a seção identificada como "mapa":
    map_box_bg, map_box_border, map_marker_color, map_marker_border,
    map_info_bg, map_info_text, map_info_border, map_info_icon_bg,
    map_info_code_color.

Eles permitem editar, respectivamente, a moldura do mapa, marcadores e cada
parte do cartão de informações. Os controles só devem aparecer no editor da
seção Mapa Interativo.
